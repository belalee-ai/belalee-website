# 碳循环饮食规划小工具 · 设计文档

- 日期：2026-06-11
- 状态：已确认（大力口头 OK）
- 产物：`tools/carb-cycle.html` 单文件本地工具

## 目标

给大力个人使用的碳循环（carb cycling）一周饮食规划工具：输入身体数据与训练课表，输出 7 天每日热量、碳水/蛋白/脂肪克数与三餐示例。减脂保肌为主目标，兼容纯减脂/增肌两档。

## 形态

单 HTML 文件（vanilla JS，无依赖），双击浏览器打开。输入数据存 localStorage，改动实时重算。瑞士风 + 品牌柠檬绿（渐变 `#d4f23f → #8fd14f`，文字绿 `#4d7c0f`，深绿 `#3f6212`，浅底 `#f7fce0`）。代码内默认值为大力数据（仅本地使用，升级公开网页版时改为通用占位值）。

## 输入

性别 / 年龄 / 身高 / 体重 / 体脂率（选填）/ 目标（减脂保肌·纯减脂·增肌）/ 单次力量消耗（默认 500 kcal）/ 单次有氧消耗（默认 500 kcal）/ 一周课表（每天：力量/有氧/休息）。

默认课表：周一·三·五力量，周日·二·四有氧，周六休息。每张日卡有"今天临时休息"开关，一键降为低碳日。

## 计算逻辑

1. **基础代谢**：填体脂率用 Katch-McArdle（370 + 21.6×瘦体重），否则 Mifflin-St Jeor。
2. **每日消耗** = 基础代谢 × 1.3（日常活动）+ 当天训练消耗。
3. **热量目标**（减脂保肌档）：高碳日（力量）−10%，中碳日（有氧）−15%，低碳日（休息）−22%；下限不低于基础代谢 ×0.95。纯减脂各档再 −5%；增肌为 +10%/+5%/0%。
4. **蛋白质固定**：减脂保肌 2.0 g/kg，其余 1.8 g/kg，三档不变。
5. **碳水分档**（减脂保肌）：高碳 3.6 g/kg、中碳 2.2 g/kg、低碳 1.0 g/kg 起算。
6. **脂肪 = 剩余热量 ÷ 9**，夹在 0.75–1.35 g/kg 之间；夹取后的热量差额回补/扣减到碳水（碳水下限 30g）。
7. **周汇总**：平均热量、平均缺口、预计周减重（周缺口 ÷ 7700）。

## 防暴食设计

- 高碳日卡片内置"计划内甜品额度 ≤180 kcal"（约 45g 碳水，已计入当日碳水），明示"想吃甜的留到今天"。
- 低碳日卡片提示"今天最难熬，想吃甜的 → 看明天高碳日"。

## 输出

7 张日卡（周一→周日）：日类型徽章（高/中/低碳）、热量、三大营养素克数、三餐+加餐示例（拳头/手掌直观单位，自动跳过猪肉）、临时休息开关。底部周汇总条 + 免责声明（预估非医嘱，以两周实际体重变化校准）。

## 边界

- 不做食物数据库、不做打卡记录、不做多人档案——YAGNI，先验证两周。
- 后续可能的升级：搬进 belalee-website 成公开页面（默认值改占位）、营养师号内容素材。
